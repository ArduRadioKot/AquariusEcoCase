# Бесплатные способы тестирования iOS приложения

## ⚠️ Важно: TestFlight требует платный аккаунт

TestFlight и публикация в App Store требуют **платный Apple Developer аккаунт ($99/год)**. Это требование Apple, и обойти его нельзя.

## 🆓 Бесплатные альтернативы

### Вариант 1: Expo Go (Самый простой способ)

**Полностью бесплатно**, но с ограничениями:

1. Установите Expo Go из App Store на iPhone
2. Запустите приложение в режиме разработки:

```bash
cd mobile
npm start
```

3. Отсканируйте QR-код в Expo Go
4. Приложение запустится на устройстве

**Ограничения:**
- Требует подключение к интернету
- Нельзя использовать нативные модули, которые не поддерживает Expo Go
- Не подходит для финального тестирования

### Вариант 2: Бесплатный Apple Developer аккаунт + Ad Hoc

**Бесплатно**, но с ограничениями:

1. Создайте бесплатный Apple ID на https://appleid.apple.com
2. Войдите в Apple Developer Portal (бесплатно)
3. Соберите приложение для Ad Hoc distribution:

```bash
cd mobile
npx eas-cli build --platform ios --profile preview
```

4. Установите на до 100 устройств (по UDID)

**Ограничения:**
- Сертификат действителен только 7 дней
- Нужно пересобирать каждую неделю
- Нельзя использовать TestFlight
- Нельзя публиковать в App Store

### Вариант 3: Локальная сборка на Mac

Если у вас есть Mac, можно собрать локально:

1. Установите Xcode
2. Соберите проект:

```bash
cd mobile
npx expo run:ios
```

**Ограничения:**
- Требует Mac
- Можно тестировать только на симуляторе или подключенном устройстве
- Нельзя распространять другим пользователям

### Вариант 4: Использовать Android версию

**Полностью бесплатно** и без ограничений:

- Android APK можно собирать и распространять бесплатно
- Уже собран APK файл: https://expo.dev/artifacts/eas/7EemrFJ8odpZaCHdfWU4s9.apk
- Можно устанавливать на любое количество устройств
- Можно распространять через любой канал

## 📱 Рекомендации

### Для быстрого тестирования:
Используйте **Expo Go** - самый простой и быстрый способ

### Для тестирования на реальных устройствах:
Используйте **бесплатный Apple Developer + Ad Hoc** (но помните про ограничение 7 дней)

### Для публикации и распространения:
Нужен **платный Apple Developer аккаунт** ($99/год) - это единственный способ для TestFlight и App Store

## 🔧 Настройка для бесплатного тестирования

### Для Expo Go:
Ничего дополнительно настраивать не нужно - просто запустите `npm start`

### Для Ad Hoc сборки:
1. Обновите `eas.json` (уже настроено)
2. Запустите сборку:
```bash
npm run build:ios
```
3. При запросе выберите бесплатный Apple ID
4. Укажите UDID устройств для тестирования

## 💡 Альтернативные платформы для распространения

Если нужна публикация без App Store:
- **TestFlight альтернативы**: Firebase App Distribution, TestFairy (бесплатные планы)
- **Enterprise distribution**: Требует Enterprise аккаунт ($299/год)
- **Веб-версия**: Можно сделать PWA (Progressive Web App) - полностью бесплатно

## ❓ Часто задаваемые вопросы

**Q: Можно ли использовать TestFlight бесплатно?**
A: Нет, TestFlight требует платный Apple Developer аккаунт.

**Q: Как долго работает бесплатный сертификат?**
A: 7 дней, после этого нужно пересобирать приложение.

**Q: Сколько устройств можно добавить в Ad Hoc?**
A: До 100 устройств по UDID.

**Q: Можно ли обновить приложение без пересборки?**
A: Только если используете Expo Go или OTA updates (требует Expo аккаунт).
