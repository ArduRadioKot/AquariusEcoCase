# Инструкция по сборке APK для Android

## Подготовка

1. Убедитесь, что у вас установлены:
   - Node.js (версия 16 или выше)
   - npm или yarn

2. Перейдите в папку mobile:
   ```bash
   cd mobile
   ```

3. Установите зависимости:
   ```bash
   npm install
   ```

## Сборка APK через EAS Build (Рекомендуемый способ)

EAS Build - это облачный сервис от Expo для сборки приложений.

### Шаг 1: Установка зависимостей

```bash
npm install
```

Это установит `eas-cli` локально в проект.

### Шаг 2: Вход в аккаунт Expo

```bash
npx eas-cli login
```

Или просто:

```bash
npm run build:android:apk
```

Команда автоматически попросит войти в аккаунт при первом запуске.

Если у вас нет аккаунта, создайте его на https://expo.dev

### Шаг 3: Инициализация проекта (если еще не сделано)

```bash
npx eas-cli build:configure
```

### Шаг 4: Сборка APK

Для сборки APK файла выполните:

```bash
npm run build:android:apk
```

Или напрямую:

```bash
npx eas-cli build --platform android --profile production
```

### Шаг 5: Скачивание APK

После завершения сборки (обычно занимает 10-20 минут), вы получите ссылку для скачивания APK файла.

## Альтернативный способ: Локальная сборка

Если вы хотите собрать APK локально, вам понадобится:

1. Android Studio с Android SDK
2. Java Development Kit (JDK)
3. Настроенные переменные окружения ANDROID_HOME

Затем выполните:

```bash
npx expo run:android --variant release
```

APK файл будет находиться в: `android/app/build/outputs/apk/release/app-release.apk`

## Примечания

- Первая сборка может занять больше времени, так как EAS создает окружение сборки
- APK файл будет иметь размер примерно 20-50 МБ
- Для установки APK на устройство Android нужно разрешить установку из неизвестных источников

## Устранение проблем

Если возникают ошибки при сборке:

1. Проверьте, что все зависимости установлены: `npm install`
2. Убедитесь, что вы вошли в аккаунт Expo: `eas whoami`
3. Проверьте конфигурацию в `eas.json` и `app.json`
4. Попробуйте очистить кэш: `expo start -c`
